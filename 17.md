## 1. Мета роботи
Опанувати практичну роботу з URL API, інтерфейсом `URLSearchParams` та History API (`pushState()`, `replaceState()`, подія `popstate`). Навчитися проєктувати єдиний об’єкт стану каталогу, будувати конвеєр обробки даних («фільтрація → сортування → пагінація»), синхронізувати стан інтерфейсу з адресним рядком у двох напрямках без перезавантаження сторінки, а також безпечно валідувати параметри з URL.

## 2. Основні фрагменти реалізованого коду
### Читання та валідація стану з URL
```javascript
function readStateFromURL() {
  const params = new URLSearchParams(window.location.search);
  const q = (params.get('q') || '').trim().slice(0, MAX_QUERY_LENGTH);
  const category = params.get('category') || CATALOG_DEFAULTS.category;
  const rawSort = params.get('sort');
  const sort = ALLOWED_SORTS.includes(rawSort) ? rawSort : CATALOG_DEFAULTS.sort;

  const rawPage = Number.parseInt(params.get('page'), 10);
  const page = Number.isInteger(rawPage) && rawPage > 0 ? rawPage : CATALOG_DEFAULTS.page;
  return { q, category, sort, page };
}
```
### Синхронізація стану з адресним рядком (History API)
```javascript
function buildCatalogURL(state) {
  const url = new URL(window.location.href);
  const params = new URLSearchParams();
  if (state.q) params.set('q', state.q);
  if (state.category !== CATALOG_DEFAULTS.category) params.set('category', state.category);
  if (state.sort !== CATALOG_DEFAULTS.sort) params.set('sort', state.sort);
  if (state.page !== CATALOG_DEFAULTS.page) params.set('page', String(state.page));

  url.search = params.toString();
  return url;
}
function syncURL(mode = 'push') {
  const newURL = buildCatalogURL(catalogState);
  if (newURL.href === window.location.href) return;

  const stateSnapshot = { ...catalogState };

  if (mode === 'replace') {
    history.replaceState(stateSnapshot, '', newURL);
  } else {
    history.pushState(stateSnapshot, '', newURL);
  }
}
```
### Конвеєр обробки даних (пагінація)
```javascript
function paginateProducts(products, page, perPage) {
  const totalItems = products.length;
  const totalPages = Math.max(1, Math.ceil(totalItems / perPage));
  const currentPage = Math.min(Math.max(page, 1), totalPages);
  const startIndex = (currentPage - 1) * perPage;
  const endIndex = startIndex + perPage;
  return {
    items: products.slice(startIndex, endIndex),
    totalItems,
    totalPages,
    currentPage,
    startIndex
  };
}
```

## 3. Відповіді на контрольні запитання
1. **Чому стан фільтрів в URL, а кошик і тема у localStorage?**  
   URL визначає публічний стан сторінки для посилань і оновлень, а кошик із темою — це приватні локальні дані користувача.
2. **Різниця між методами URLSearchParams (`get`, `set`, `append`, `delete`)?**  
   `get` читає перше значення, `set` встановлює/перезаписує, `append` додає дублікат ключа, `delete` видаляє. `URLSearchParams` зручніший за склеювання рядків, бо сам робить правильне URL-кодування.
3. **Чому `location.search` перезавантажує сторінку, а `pushState()` ні?**  
   Зміна `location.search` ініціює новий запит до сервера. `pushState()` змінює лише адресний рядок у браузері програмно без запиту на сервер.
4. **Чому `pushState` для категорії/сторінки, а `replaceState` для пошуку?**  
   `pushState` створює нові кроки в історії (для зручності кнопкою «Назад»), а `replaceState` оновлює поточний запис, щоб живий пошук при кожній літері не засмічував історію браузера.
5. **Коли генерується `popstate` і чому там не можна робити `pushState`?**  
   Виникає при натисканні «Назад/Вперед» у браузері. Виклик `pushState` всередині неї заборонений, щоб не зламати стек історії і не створити цикли.
6. **Чому `slice()` виконується останнім у конвеєрі?**  
   Спочатку треба відфільтрувати і відсортувати всі товари, і лише потім нарізати їх на сторінки. Якщо нарізати до — отримаємо випадкові елементи.
7. **Як працює пагінація (`startIndex`, `endIndex`, перевищення довжину)?**  
   `startIndex = (page - 1) * perPage`, а `endIndex = startIndex + perPage`. Якщо `endIndex` більший за масив, `slice()` просто бере елементи до самого кінця без помилок.
8. **Навіщо копія масиву `[...products]` у `sortProducts()`?**  
   Метод `sort()` мутує (змінює) оригінальний масив. Копія захищає вихідні дані (`allProducts`) від зміни порядку.
9. **Які загрози без валідації і як захищалися?**  
   Без валідення є ризики збоїв та XSS-атак. Захист реалізовано через білі списки, `parseInt` з перевірками та виведення через `textContent` замість `innerHTML`.
10. **Чому при зміні фільтрів сторінка скидається на 1?**  
    Щоб не опинитися на неіснуючій сторінці, якщо нова вибірка товарів менша за попередню.
11. **Як працює `debounce`?**  
    Відкладає виконання функції (на 300 мс) і скидає таймер при кожному новому натисканні, щоб не перевантажувати пошук на кожну введену літеру.
